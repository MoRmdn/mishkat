Rules
Optional. Show the sheet at most once per version, then no more often than every 3 days. Never show it mid-session in the reader or while a reminder notification is being opened. Choosing Later keeps it quiet for that version until the next launch after 3 days.
Android. Use Play In-App Updates: FLEXIBLE for optional updates (a download banner, then "Restart"), and IMMEDIATE for required ones.
iOS. Apps can't install updates themselves, so both buttons open the App Store page. The flexible-download states only exist on Android.
Required. This blocks sync, account and reminder scheduling changes. Reading the bundled athkar can stay open behind "متابعة القراءة فقط" (the allowReading tweak), because reading never touches the server. Existing scheduled reminders keep firing.
Offline. If Remote Config can't be fetched, use the last cached values and never block on a failed fetch.
